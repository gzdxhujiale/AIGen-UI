# AIGen-UI 动态工作台分区原型描述

本文档详细描述了动态工作台（Page1）中四个核心分区（筛选区、操作区、卡片区、表格区）的功能逻辑、交互规则及视觉表现，旨在指导后续的 UI 设计与开发实现。

## 1. 筛选区 (Filter Area)

### 1.1 功能描述
筛选区作为用户获取目标数据的核心入口，支持动态配置多种类型的筛选组件。其主要职责是根据用户输入的条件，实时或手动触发数据列表的过滤查询。

### 1.2 UI 展现
*   **布局容器**：采用 CSS Grid 网格布局，支持自定义配置每行显示的列数（1~6列）及组件间距（Gap）。
*   **组件类型**：
    *   **文本输入 (Input)**：用于关键词模糊搜索。
    *   **下拉选择 (Select)**：提供预设选项的单选/多选。
    *   **日期范围 (Date Range)**：用于时间段筛选。
    *   **树形选择 (Tree Select)**：用于层级数据的选择（如部门、分类）。
*   **视觉风格**：组件统一采用 Arco Design 或 Shadcn/UI 风格，保持高度一致性。在“编辑模式”下，每个筛选组件显示外边框及编辑/删除快捷操作入口。

### 1.3 交互逻辑
*   **响应式布局**：根据容器宽度自动调整组件宽度，确保整齐排列。
*   **拖拽排序**：（编辑模式下）用户可拖拽筛选组件调整排列顺序。
*   **状态保持**：组件值双向绑定至 `uiState.filters`，确保筛选条件与数据请求参数实时同步。

### 1.4 组件配置 (Configuration)
*   **交互操作**：
    *   **添加**：点击区域头部的 `+ 添加筛选` 按钮。
    *   **编辑/删除**：在编辑模式下，悬浮组件点击 `笔形图标` 或 `垃圾桶图标`。
*   **配置表单项**：
    *   **字段名 (Key)**: 唯一标识符，对应数据查询参数的 Key（如 `status`）。
    *   **显示标签 (Label)**: 筛选框上方的标题（如 `订单状态`）。
    *   **类型 (Type)**:
        *   `Input` (输入框)：支持占位符提示。
        *   `Select` (下拉框)：需配置 **选项列表** (逗号分隔，如 `进行中,已完成,已关闭`)。
        *   `Date Range` (日期范围)：起止时间选择。
        *   `Tree Select` (树形选择)：需配置 **树形数据 JSON**。
    *   **占位文字 (Placeholder)**: 输入框或选择框内的提示文本。

## 2. 操作区 (Operation Area)

### 2.1 功能描述
操作区承载页面的主要功能指令，如“新建”、“导出”、“批量删除”等。它决定了用户可以在该页面执行哪些业务操作。

### 2.2 UI 展现
*   **按钮样式**：支持多种变体配置，包括 `Primary`（主按钮）、`Outline`（描边按钮）、`Text`（文本按钮）等，支持绑定图标。
*   **布局模式**：提供两种布局策略，可通过配置切换：
    1.  **融合模式 (Fusion Mode)**：按钮组紧随筛选组件之后，智能计算剩余网格空间进行填充，空间不足时自动换行。
    2.  **独立行模式 (Separate Mode)**：按钮组位于筛选区下方的独立行，靠右对齐，与筛选条件有明显的视觉分隔线。

### 2.3 交互逻辑
*   **点击反馈**：点击按钮可触发预设的“效果 (Effect)”，包括：
    *   **模态框 (Modal)**：弹出一个包含表单的对话框，用于数据录入或确认。
    *   **关联列表 (Table)**：弹窗展示关联页面的表格数据。
    *   **无 (None)**：直接触发自定义逻辑（如页面跳转或即时操作）。
*   **编辑功能**：（编辑模式下）支持添加新按钮、修改按钮文本/样式/触发效果、以及删除按钮。

### 2.4 组件配置 (Configuration)
*   **交互操作**：
    *   **添加**：点击区域头部的 `+ 添加按钮` 按钮。
    *   **编辑/删除**：在编辑模式下，悬浮按钮点击 `笔形图标` 或 `垃圾桶图标`。
*   **配置表单项**：
    *   **Key**: 按钮唯一标识（如 `btn_export`）。
    *   **按钮文本 (Label)**: 按钮上显示的文字（如 `导出报表`）。
    *   **样式 (Variant)**:
        *   `Primary`: 主色按钮（实心）。
        *   `Outline`: 描边按钮（默认）。
        *   `Text`: 纯文本按钮。
        *   `Shadcn Outline`: Shadcn 风格描边。
    *   **交互效果 (Effect Type)**:
        *   `None` (无反应)：仅触发点击事件（需开发对接）。
        *   `Modal` (弹窗-表单)：点击后弹出表单对话框。需配置 **弹窗标题**、**内容描述** 及 **动态表单项**（支持定义多个 Input/Select 字段）。
        *   `Table` (弹窗-表格)：点击后弹出包含表格的对话框。需选择 **关联表格页面**（从现有页面中选择）。

## 3. 卡片区 (Card Area)

### 3.1 功能描述
卡片区作为“数据概览”或“快捷看板”，位于筛选操作区与主体表格之间。主要用于展示关键指标（KPI）、统计数据或业务状态概览。

### 3.2 UI 展现
*   **布局**：独立的网格容器，支持自定义列数（默认为4列）及间距。
*   **卡片样式**：每个卡片包含 `Title`（指标说明）和 `Data`（具体数值/内容）。支持配置卡片的宽度和高度。
*   **显隐控制**：可以通过全局配置一键显示或隐藏整个卡片区域。

### 3.3 交互逻辑
*   **数据展示**：卡片内容静态展示配置的数据，后续可扩展为动态获取统计接口数据。
*   **编辑管理**：（编辑模式下）提供直观的“添加卡片”、“编辑卡片内容”、“删除卡片”入口，支持可视化调整概览布局。

### 3.4 组件配置 (Configuration)
*   **交互操作**：
    *   **添加**：点击区域头部的 `+ 添加卡片` 按钮。
    *   **编辑/删除**：在编辑模式下，悬浮卡片点击 `笔形图标` 或 `垃圾桶图标`。
    *   **区域设置**：点击 `配置` 按钮可调整列数和间距。
*   **配置表单项**：
    *   **Key**: 唯一标识。
    *   **标题 (Title)**: 卡片顶部的指标名称（如 `总销售额`）。
    *   **数据 (Data)**: 卡片中心展示的核心数值或文本（如 `¥ 50,000`）。
*   **全局配置**：
    *   **列数 (Columns)**: 每行展示的卡片数量（1~6）。
    *   **间距 (Gap)**: 卡片之间的像素间距（如 `16px`）。
    *   **显示开关**: 控制卡片区域的整体显示/隐藏。

## 4. 表格区 (Table Area)

### 4.1 功能描述
表格区是工作台的核心内容载体，以结构化的行/列方式展示业务数据。支持复杂的数据展示格式和行内操作。

### 4.2 UI 展现
*   **表格控件**：基于 Arco Design Table 或等效组件封装，包含表头和数据体。
*   **列配置**：
    *   **文本列**：直接展示字段值。
    *   **状态/条件列**：根据条件渲染不同颜色或文本（Mock数据支持条件生成）。
    *   **操作列**：行内按钮组，用于处理单条数据。
*   **功能特性**：
    *   **分页器**：底部固定分页控件，支持调整每页条数（PageSize）。
    *   **多选**：首列可选开启复选框（Checkbox），用于批量操作。
    *   **滚动配置**：支持自定义高度限制（触发纵向滚动）和列宽总和（触发横向滚动）。
    *   **表头吸顶**：支持表头固定，防止长列表滚动时表头消失。

### 4.3 交互逻辑
*   **Mock 数据引擎**：在未接入真实后端时，内置 `MockHelper` 根据列配置（类型、规则）自动生成仿真数据，确保演示效果逼真。
*   **列管理**：（编辑模式下）支持拖拽表头调整列宽和列顺序，支持实时添加新列或修改列属性（如对齐方式、宽度、固定列等）。
*   **空状态**：无数据时展示标准的 Empty 占位图。

### 4.4 组件配置 (Configuration)
*   **交互操作**：
    *   **添加**：点击表格上方的 `+ 添加列` 按钮。
    *   **编辑/删除**：在编辑模式下，悬浮表头点击 `笔形图标` 或 `垃圾桶图标`。
    *   **拖拽排序**：直接拖拽表头可调整列顺序。
*   **配置表单项**：
    *   **基础属性**:
        *   **Key**: 对应数据源中的字段名（如 `create_time`）。
        *   **显示标签 (Label)**: 表头文字。
        *   **宽度 (Width)**: 列宽（如 `150px`）。
        *   **固定方式**: `不固定` / `左侧固定` / `右侧固定`。
        *   **对齐方式**: `左对齐` / `居中` / `右对齐`。
    *   **显示类型 (Type)**:
        *   `Text`: 普通文本。
        *   `Badge`: 徽标样式。
        *   `Status Badge`: 状态圆点+文字。
        *   `Text Button`: 文字按钮组（如 `编辑,删除`）。
    *   **Mock 数据规则**:
        *   `Mock Format`: 选择生成规则（时间、数字、列表随机、条件判断等）。
        *   `Condition Rules`: (当选条件判断时) 定义 `当 [列A] [等于] [值1] 时显示 [文本X]` 的逻辑。
*   **全局配置**：
    *   **高度限制 (Height)**: 设置表格最大高度（如 `400px`），超出自动纵向滚动。
    *   **分页大小 (Page Size)**: 默认每页条数。
    *   **显示复选框 (Checkbox)**: 是否开启行首多选框。
    *   **吸顶表头 (Sticky Header)**: 滚动时表头是否固定。

## 6. 配置项定义 (Configuration Requirements)

各分区需支持以下核心配置项，以满足业务的灵活定义需求：

### 6.1 筛选区配置项
*   **基础属性**：必须包含字段唯一标识（Key）和前端显示名称（Label）。
*   **组件类型**：需支持文本输入、下拉单选/多选、日期范围选择、树形结构选择。
*   **数据源**：下拉和树形组件需支持配置静态选项列表（如“男/女”）或由层级结构数据填充。
*   **默认值**：支持预设默认筛选条件。

### 6.2 操作区配置项
*   **按钮定义**：包括按钮名称、唯一标识、以及视觉样式（主按钮/次按钮/文字按钮）。
*   **触发行为**：
    *   **无操作**：仅作为占位，等待开发对接。
    *   **打开弹窗**：配置弹窗标题及内部表单项。
    *   **打开关联页**：配置关联的目标页面 ID。

### 6.3 表格区配置项
*   **容器设置**：支持定义表格高度（用于固定表头滚动）和每页显示条数。
*   **列定义**：
    *   **数据映射**：每列需指定对应的数据字段名。
    *   **展示格式**：支持普通文本、状态徽标、操作按钮组。
    *   **视觉调整**：列宽、对齐方式、是否固定在左/右侧。
    *   **数据模拟规则**：支持定义该列是“日期”、“金额”还是“状态枚举”，以便在预览模式下生成逼真的演示数据。
    *   **条件渲染**：需支持简单的逻辑判断（如：当 [状态] 等于 [1] 时，显示“已完成”）。

## 7. 业务规则与交互逻辑 (Business Rules)

### 7.1 筛选与列表联动
*   **自动查询**：用户修改筛选条件（如切换下拉框选项、确认日期范围）后，列表应自动刷新显示匹配的数据。
*   **手动查询**：若配置了“查询”按钮，则需用户点击后才触发一次性查询（适用于复杂筛选场景）。
*   **参数同步**：筛选条件的变更建议同步到 URL 参数中，以便用户分享当前查询状态的链接。

### 7.2 数据模拟 (Mock) 机制
为了在后端接口尚未开发完成时也能演示原型，系统需具备智能模拟能力：
*   **智能生成**：根据每一列配置的“数据模拟规则”，自动填充合理的假数据（例如：时间列自动生成最近一月的时间，金额列生成随机数字）。
*   **关联生成**：若列配置了条件判断（如状态列），展示的数据必须符合设定的逻辑（如状态码 1 对应“成功”），不能出现逻辑矛盾的数据。

### 7.3 异常与边界处理
*   **数据加载失败**：当网络或接口异常时，表格区域不应留白，而应展示“加载失败”提示页，并提供“点击重试”操作。
*   **配置为空或错误**：若页面未读取到有效配置，应引导用户进入“初始化配置向导”，而不是展示报错代码。
*   **权限控制**：配置中标记为“不可见”的组件，在界面上必须完全隐藏，确保无权限用户无法通过其它方式触发。
*   **内容展示优化**：
    *   表格内容过长时，默认显示省略号，鼠标悬停显示完整内容。
    *   卡片数据应自适应字体大小，防止数值溢出容器。
