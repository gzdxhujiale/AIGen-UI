## 1. 前言

### 1.1 编写目的

本文档旨在帮助用户快速熟悉 **AIGen-UI** 系统的功能布局及业务操作流程，详细说明了系统界面的各个组成部分，特别是工作区的交互逻辑，以提升用户的使用效率。

### 1.2 适用对象
- **系统管理员**：负责页面配置、导航菜单管理及团队设置。
- **产品经理**：快速搭建、修改中后台产品可交互的页面原型。

## 2. 快速入门

### 2.1 登录环境

- **推荐浏览器**：Chrome (谷歌浏览器) 80+ 版本、Edge 浏览器。
- **系统地址**：http://aigenui.hujiale.works

## 3. 系统界面概览



登录系统后，主界面采用现代化的布局设计，包含以下核心区域：

### 3.1 左侧导航栏 (Left Sidebar)
系统左侧为主要的导航与组织区域：
- **团队切换器 (Team Switcher)**：顶部下拉菜单，用于在不同团队/项目空间之间切换。
- **主导航菜单 (Main Navigation)**：按业务分组展示的一级和二级菜单。
    - **折叠/展开**：支持点击箭头折叠子菜单。
    - **编辑状态**：在编辑模式下，支持直接添加一级/二级菜单，并通过拖拽调整顺序。


### 3.2 顶部菜单栏 (Top Menu Bar)
页面顶部的横向工具栏：
- **面包屑导航 (Breadcrumb)**：显示当前页面的路径位置（如：首页 > 用户管理 > 列表），支持快速回退。
- **顶部快捷菜单 (Header Menu)**：右侧自定义功能区。
    - **常规状态**：显示快捷按钮（如"帮助文档"）或下拉菜单（如"快速操作"）。
    - **编辑状态**：支持添加自定义按钮或下拉菜单，并可拖拽排序。
- **用户头像 (User Profile)**：顶部右侧，显示当前登录用户的头像和名称。点击可弹出菜单，进行 "编辑模式切换"、"用户中心" 或 "退出登录" 操作。

### 3.3 主内容区 (Main Content Area)
核心业务操作区域，通常由以下四个功能区块组成：
1.  **筛选区 (Filter Area)**：位于页面顶部，提供多条件的查询输入（文本、下拉、日期等）。支持收起/展开。
2.  **功能区 (Actions Area)**：位于筛选区右下侧，包含全局操作按钮（如"新建"、"导出"、"批量删除"）。
3.  **卡片区 (Card Area)**：用于展示统计指标或概览信息（如"总用户数"、"今日营收"）。通常位于表格上方。
4.  **表格区 (Table Area)**：核心数据展示区域，支持分页、列宽调整、复选框选择及行内操作。

## 4. 核心功能操作指南

### 4.1 预览模式 (Preview Mode)
系统默认进入的状态即为**预览模式**。
- **只读体验**：在此模式下，所有页面配置被锁定，界面整洁无干扰。
- **业务操作**：您可以正常使用筛选查询、查看图表、点击按钮执行业务逻辑。
- **数据展示**：表格区会根据配置的 Mock 规则（后续版本将迭代真实API）展示动态数据。

### 4.2 编辑模式
如需修改页面布局或配置，请点击左侧底部用户头像，选择 **"编辑模式" **。
进入编辑模式后，界面会出现蓝色的辅助虚线框和编辑图标 (✏️)。

#### 4.2.1 筛选区配置 (Filter Configuration)
- **编辑**：鼠标移动到对应筛选项区域，浮现编辑图标，点击后将会弹窗出对应的表单，在表单内进行修改即可。
- **新增**：点击区域内的 `+ 添加筛选` 按钮。
- **删除**：鼠标移动到对应筛选列的区域，浮现删除图标，点击对应筛选框内的 `删除`图标 按钮，并确认删除。
- **修改**：
    - **Key**: 对应 API 参数名。
    - **Label**: 显示名称。
    - **Type**: 支持 Input (输入框), Select (下拉), DateRange (日期范围), TreeSelect (树形选择)。
    - **Options**: 为下拉框定义选项 (如 `渠道A, 渠道B, 渠道C`)。
- **排序**：直接拖拽筛选项即可调整显示顺序。

#### 4.2.2 功能区配置 (Action Configuration)
- **编辑**：鼠标移动到对应按钮区域，浮现编辑图标，点击后将会弹窗出对应的表单，在表单内进行修改即可。
- **新增**：点击 `+ 添加按钮`。
- **删除**：鼠标移动到对应按钮的区域，浮现删除图标，点击对应筛选框内的 `删除`图标 按钮，并确认删除。
- **交互效果 (Effect Type)**：
    - **None**: 普通按钮，仅触发事件。
    - **Modal**: 点击弹出模态框，可配置表单项。
    - **Table**: 点击弹出关联表格（需指定目标页面 ID）。
- **样式**：可选择 Solid, Outline, Text 等多种样式。

#### 4.2.3 卡片区配置 (Card Configuration)
- **管理**：点击区域右上角的 `配置` 按钮可开启/关闭卡片显示。
- **编辑**：鼠标移动到对应卡片区域，浮现编辑图标，点击后将会弹窗出对应的表单，在表单内进行修改即可。
- **新增**：点击添加卡片并设置 `Title` (标题) 和 `Data` (数值)。
- **删除**：鼠标移动到对应卡片区域，浮现删除图标，点击对应筛选框内的 `删除`图标 按钮，并确认删除。

#### 4.2.4 表格区配置 (Table Configuration)
这是表格区域的配置区域：
- **新增列**：点击 `+ 添加列`。
- **删除**列：移动到对应列的表头，浮现删除图标，点击对应筛选框内的 `删除`图标 按钮，并确认删除。
- **列属性**：
    - **Width**: 设置固定宽度或自适应。
    - **Type**: Text (文本), Button (按钮组), Badge (徽标)。
    - **Mock Format**: **极重要**。设置此项可自动生成模拟数据（如 `datetime`, `money`, `conditional`）。
- **条件样式**：通过 `Condition Rules` 可以设置某列数值的条件，满足条件该列就会显示对应内容。

### 4.3 AI 助手与页面生成
系统内置了强大的 AI 辅助生成引擎。

1.  **唤起助手**：点击页面右下角的悬浮按钮 (✨)。
2.  **自然语言对话**：
    - 输入指令：*"新增用户管理，可以筛选用户ID、用户姓名，用户渠道（分为Google、Apple），创建时间。有查询、重置按钮。列表有用户ID、用户姓名、用户渠道、操作列"
3.  **实时预览**：AI 生成配置后，页面会立即刷新展示效果。
    - **确认追加**：满意后点击确认，配置将追加ai生成的新页面。
    - **取消**：放弃本次生成，不保存本次修改。

### 4.4 用户中心

点击左侧底部用户头像 -> **"用户中心"** 进入。

- **基本信息**：
    - **头像**：点击头像区域可上传新图片。
    - **昵称**：修改显示名称。
- **团队管理**：
    - **创建团队**：点击 `新增团队`，设置团队名称。
    - **权限配置**：为不同团队设置可见的菜单权限（暂时无实际功能，后续版本将迭代不同团队的菜单配置）。
    - **切换团队**：在左侧导航栏顶部的下拉菜单中切换当前激活的团队空间。

## 5. 常见问题解答 (FAQ)

**Q1：其他用户的编辑模式下的修改会影响我吗？**
> **A**：不会。配置是实时保存到云端数据库对应的用户账户内。您的修改只会对您登录的用户生效。

**Q2：如何恢复误删的配置？**
> **A**：目前系统支持实时保存。如果误操作，请重新手动重新添加，后续版本迭代将支持 回滚操作。

**Q3：Mock 数据是如何生成的？**
> **A**：Mock 数据完全基于表格列的 `Mock Format` 配置在前端动态生成，不依赖后端接口，方便快速原型展示。
